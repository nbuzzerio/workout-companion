# W01-02 implementation checkpoint

Replaces the baseline screen with a responsive workout runner using the existing
Monday DEMO plan. Other weekdays explicitly have no plan. Date-based practice,
previous completed DEMO values, typed set editors, local draft recovery, explicit
save confirmation, reopening, read-only completion and a set-count summary are
implemented. No imports, external services or new dependencies were introduced.
Dumbbell units are pounds as logged; the source does not establish per-hand versus
combined load. Machine positions are separate from weight. Holds use seconds.

Draft recovery uses a separate localStorage key; IndexedDB remains the workout
history authority. Draft retention is explicitly different from a saved workout.
Failed draft writes keep edits on screen and warn against leaving. Unsaved edits
also install a beforeunload warning. Switching weekdays retains the active draft;
dates/history navigation require a save or confirmed discard. Invalid recovery
data is retained, reported, and prevents starting a replacement draft.
